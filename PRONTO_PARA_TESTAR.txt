🚀 COMO TESTAR (8 PASSOS SIMPLES):

1️⃣  Abra seu navegador
    URL: http://localhost:8080

2️⃣  Faça login no GLPI

3️⃣  Configure permissões (IMPORTANTE!)
    Caminho: Configuração → Perfis → [Seu Perfil] → Aba "flowBPMN"
    Ação: Marque TUDO como "Sim"

4️⃣  Teste a configuração
    URL: http://localhost:8080/plugins/flowbpmn/front/config.form.php
    Deve carregar formulário sem erros

5️⃣  Crie um ticket de teste
    Menu: Assistência → Tickets → Botão "+"
    Título: "Teste flowBPMN"

6️⃣  Desenhe um fluxo BPMN
    - Abra o ticket
    - Clique na aba "flowBPMN" (tem ícone de diagrama)
    - Espere carregar (~2-3 seg)
    - Arraste: Start → Task → End
    - Conecte os elementos

7️⃣  Salve o diagrama
    - Clique no botão "Salvar" (canto superior)
    - Aguarde: "Fluxo flowBPMN salvo com sucesso!"

8️⃣  Verifique o PNG anexado
    - Role até "Documentos" no ticket
    - Deve ter um PNG novo
    - Clique para ver seu diagrama

════════════════════════════════════════════════════════════════

💡 TESTE EXTRA: Versionamento

  1. Modifique o diagrama (adicione uma task)
  2. Salve novamente
  3. Clique no botão "Versões"
  4. Veja o histórico
  5. Clique em "Restaurar" numa versão
  6. Diagrama volta para versão anterior
