❌ PROBLEMA IDENTIFICADO:

O plugin estava sendo ativado e imediatamente desativado devido a um
erro no sistema de traduções. As variáveis globais $TRANSLATE e $LANG
estavam causando conflito durante a inicialização.


✅ CORREÇÃO APLICADA:

1️⃣  setup.php:
   - Removida variável global $LANG desnecessária
   - Simplificado carregamento de traduções
   - Adicionado verificação de $_SESSION antes de carregar
   - Usando Plugin::getPhpDir() para melhor compatibilidade

2️⃣  locales/pt_BR.php:
   - Removido sistema complexo de registro de traduções
   - Simplificado para usar apenas $LANG['plugin_flowbpmn']
   - Removidas manipulações de $TRANSLATE que causavam erro

💡 POR QUE ISSO ACONTECEU?

O GLPI tem um sistema específico de carregamento de traduções.
Ao tentar usar variáveis globais complexas ($TRANSLATE), estava
causando um erro fatal silencioso que desativava o plugin.

A solução foi simplificar para usar apenas o método padrão do GLPI:
$LANG['plugin_flowbpmn'][...]
