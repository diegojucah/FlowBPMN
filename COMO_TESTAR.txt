═══════════════════════════════════════════════════════════════════
  🔧 MÉTODO 2: INSTALAÇÃO MANUAL
═══════════════════════════════════════════════════════════════════

1. Criar ZIP:
   cd /home/diego/glpi11
   zip -r flowBPMN.zip flowBPMN/

2. Copiar para Docker:
   docker cp flowBPMN.zip 4a5500931c39:/tmp/

3. Instalar no Docker:
   docker exec -it 4a5500931c39 bash
   cd /tmp
   unzip -o flowBPMN.zip
   rm -rf /var/www/glpi/plugins/flowBPMN
   mv flowBPMN /var/www/glpi/plugins/
   chown -R www-data:www-data /var/www/glpi/plugins/flowBPMN
   exit

PROBLEMA: Plugin não aparece na lista
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Solução:
1. Verificar permissões:
   docker exec 4a5500931c39 ls -la /var/www/glpi/plugins/
   docker exec 4a5500931c39 chown -R www-data:www-data /var/www/glpi/plugins/flowBPMN

2. Verificar logs:
   docker exec 4a5500931c39 tail -50 /var/www/glpi/files/_log/php-errors.log

PROBLEMA: Erro ao instalar plugin
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Solução:
1. Verificar compatibilidade:
   - GLPI 11.0.0 ou superior
   - PHP 8.0 ou superior

2. Verificar banco de dados:
   docker exec 4a5500931c39 mysql -u root -p glpi -e "SHOW TABLES LIKE 'glpi_plugin_flowbpmn%';"

3. Limpar tabelas antigas se existirem:
   docker exec 4a5500931c39 mysql -u root -p glpi << SQL
   SET FOREIGN_KEY_CHECKS = 0;
   DROP TABLE IF EXISTS glpi_plugin_flowbpmn_flows;
   DROP TABLE IF EXISTS glpi_plugin_flowbpmn_versions;
   DROP TABLE IF EXISTS glpi_plugin_flowbpmn_profiles;
   DROP TABLE IF EXISTS glpi_plugin_flowbpmn_configs;
   SET FOREIGN_KEY_CHECKS = 1;
   SQL

PROBLEMA: Aba BPMN Flow não aparece
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Solução:
1. Verificar permissões do perfil:
   Configurar → Perfis → [Seu Perfil] → Aba BPMN Flow
   Marcar "Visualizar"

2. Limpar cache:
   docker exec 4a5500931c39 rm -rf /var/www/glpi/files/_cache/*

PROBLEMA: Erro ao salvar diagrama
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Solução:
1. Verificar console do navegador (F12)
2. Verificar logs PHP:
   docker exec 4a5500931c39 tail -f /var/www/glpi/files/_log/php-errors.log
3. Verificar permissões de edição no perfil

PROBLEMA: Erro ao desinstalar
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Solução:
1. Já foi corrigido com SET FOREIGN_KEY_CHECKS
2. Se ainda houver problema, remover manualmente:
   docker exec 4a5500931c39 mysql -u root -p glpi << SQL
   SET FOREIGN_KEY_CHECKS = 0;
   DROP TABLE IF EXISTS glpi_plugin_flowbpmn_versions;
   DROP TABLE IF EXISTS glpi_plugin_flowbpmn_flows;
   DROP TABLE IF EXISTS glpi_plugin_flowbpmn_profiles;
   DROP TABLE IF EXISTS glpi_plugin_flowbpmn_configs;
   SET FOREIGN_KEY_CHECKS = 1;
   SQL
