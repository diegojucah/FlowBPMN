🚀 COMO TESTAR (PASSO A PASSO):

1️⃣  ABRA O TERMINAL e execute este comando:

    sudo docker exec 4a5500931c39 tail -f /var/log/apache2/error.log | grep flowBPMN

    ⚠️ DEIXE ESTE TERMINAL ABERTO!
    Você verá os logs aparecerem em tempo real


2️⃣  ABRA OUTRA ABA DO NAVEGADOR:

    http://localhost:8080


3️⃣  CRIE UM TICKET DE TESTE:

    - Menu: Assistência → Tickets
    - Clique no botão "+"
    - Título: "Teste flowBPMN - Salvamento"
    - Descrição: "Testando salvamento com logs"
    - Clique em "Adicionar"


4️⃣  ABRA O TICKET CRIADO:

    - Clique na aba "flowBPMN"
    - Aguarde o editor carregar (~2-3 segundos)


5️⃣  DESENHE UM DIAGRAMA SIMPLES:

    - Arraste um "Start Event" (círculo verde)
    - Arraste uma "Task" (retângulo)
    - Arraste um "End Event" (círculo vermelho)
    - Conecte os elementos clicando e arrastando


6️⃣  SALVE O DIAGRAMA:

    - Clique no botão "Salvar" (canto superior direito)
    - OBSERVE O TERMINAL COM OS LOGS!

🐛 POSSÍVEIS ERROS E SOLUÇÕES:

ERRO: "Sessão inválida ou expirada"
→ Faça logout e login novamente no GLPI


ERRO: "Permissão negada"
→ Vá em Configuração → Perfis → [Seu Perfil] → flowBPMN
→ Marque todas as permissões como "Sim"


ERRO: "Failed to create flow in database"
→ Problema com a tabela do banco de dados
→ Pode precisar reinstalar o plugin


ERRO: "PluginFlowbpmnProfile class not found"
→ Classes do plugin não estão carregando
→ Veja se o plugin está ativado
